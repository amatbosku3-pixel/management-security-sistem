MODUL OPERASIONAL 1

Access Control & Gate Security Management

Pengendalian arus keluar masuk kendaraan unit batubara, logistik, BBM, dan tamu di seluruh portal tambang.

🚗 Fitur Utama Access Control

  • Pencatatan IN & OUT: Waktu presisi milidetik, nomor unit polisi/lambung, nama driver, perusahaan vendor.
  • Verifikasi Dokumen: Validasi nomor Delivery Order (DO), Surat Pengantar Barang (SPB), dan izin lintas.
  • Status Verifikasi: ALLOWED (Diizinkan), DENIED (Ditolak), dan VERIFICATION (Pemeriksaan Lanjutan).
  • Pemeriksaan Muatan: Pengecekan segel fisik trailer batubara dan tangki BBM.

ALUR KERJA PETUGAS GATE

1 Unit tiba di Gate (Simpang Wara / POP Paringin / Pasar Panas).
2 Petugas membuka Mobile Field Portal di HP & input nomor unit + DO.
3 Pilih status (ALLOWED / DENIED) lalu klik Simpan Transaksi.
4 KPI Kendaraan & Log di Master Command Center ter-update otomatis.
Pencegahan unit tak berizin (Illegal Hauler) dan perlindungan integritas tonase batubara perusahaan.

MODUL OPERASIONAL 4

Incident Management & Investigation Lifecycle

Siklus investigasi insiden keamanan mulai dari pelaporan darurat hingga penutupan kasus resmi.

1

OPEN / LAPORAN

Petugas menginput kejadian via mobile dengan kategori keparahan (Critical/Alert/Warning).

2

INVESTIGATING

Supervisor menugaskan Tim Reaksi Cepat / Investigasi ke titik koordinat kejadian.

3

ACTION TAKEN

Tindakan pengamanan, pengamanan barang bukti, koordinasi dengan aparat, dan pemulihan.

4

RESOLVED & CLOSED

Penyusunan Berita Acara (BAP), penutupan kasus resmi oleh Security Manager & arsip PDF.

Dilengkapi Galeri Bukti Foto, Kronologi Waktu, dan Log Investigasi Digital. Zero Tolerance Policy
MODUL OPERASIONAL 5

External Threat Intelligence & Auto-Alert Escalation

Deteksi dini potensi demonstrasi warga, blokade jalan hauling, dan rantai eskalasi otomatis berstandar SOP.

📢 Kategori Intelijen Keamanan

  • • Rencana Aksi Demo Warga: Isu kompensasi debu/lahan, kontak tokoh masyarakat.
  • • Kumpulan Massa di Jalur Hauling: Indikasi titik kumpul pinggir jalan.
  • • Potensi Blokade Jalan: Tindakan pencegahan penutupan akses logistik.
  • • Gesekan Sosial & Konflik: Deteksi dini potensi perselisihan.

🚨 Rantai Notifikasi Otomatis (Auto-Alert)

Level WARNING: Terkirim ke Security Supervisor & External Threat Officer.
Level ALERT: Terkirim ke Security Supervisor + Security Manager + Patroli Terdekat.
Level CRITICAL: Terkirim ke seluruh jajaran Manajemen Eksekutif & memicu pengamanan rute darurat.
Memastikan jalur hauling tetap beroperasi lancar (*Business Continuity*) dan bebas hambatan.

PENGATURAN & OTORISASI

Role-Based Access Control (RBAC) Matrix

9 peran hierarkis untuk menjamin kepatuhan tata kelola keamanan informasi dan operasi.

1. SECURITY MANAGER

Pemilik penuh Command Center, penetapan status siaga, ekspor laporan manajemen.

2. SECURITY SUPERVISOR

Pengendali operasional, verifikasi insiden, penugasan personil patroli & closing log.

3. ADMIN SISTEM

Konfigurasi database, API Maps, master data lokasi, user roster & audit log.

4. GATE SECURITY

Pencatatan transaksi portal, surat jalan kendaraan batubara & log tamu.

5. PATROL OFFICER

Input checkpoint patroli, inspeksi gembok & aset terjaga via mobile portal.

6. INCIDENT OFFICER

Pencatatan kronologi kejadian darurat, pengamanan bukti foto & BAP awal.

7. THREAT OFFICER

Pencatatan data intelijen lapangan dan pemantauan aksi demonstrasi.

8. ASSET OFFICER

Pemeriksaan segel fisik muatan batubara, tangki BBM, dan material vital.

9. MANAGEMENT

Tampilan eksekutif read-only untuk monitoring level siaga dan tren keamanan.

Ubah peran secara instan melalui Role Switcher di pojok kanan atas Header untuk simulasi.

PANDUAN PRAKTIS • STANDAR OPERASIONAL

Panduan Penggunaan Langkah-demi-Langkah (SOP)

Panduan praktis harian bagi Danru di Command Center dan Personil di Lapangan.

A. SOP OPERATOR COMMAND CENTER / DANRU:
  1. Buka http://localhost:5173/ di layar TV/Monitor Command Center.
  2. Periksa Threat Level Card & 7 KPI Cards di bagian atas.
  3. Pantau peta satelit, pastikan seluruh jalur hauling berwarna hijau (Open).
  4. Klik tombol Link Petugas Lapangan untuk membagikan QR Code ke regu jaga yang masuk shift.
  5. Bila ada alert merah berkedip (insiden/segel rusak), segera hubungi personil terdekat untuk verifikasi.
  6. Di akhir shift, buka menu Reports & Analytics dan cetak PDF Laporan Shift.
B. SOP PERSONIL JAGA & PATROLI LAPANGAN:
  1. Scan QR Code dari Danru atau buka link di browser HP: /#/mobile.
  2. Isi Nama & NRP Anda di baris identifikasi atas.
  3. Petugas Gate: Input setiap kendaraan masuk/keluar pada tab 🚗 Gate Access.
  4. Petugas Patroli: Tiba di aset vital (Genset/Tangki BBM), buka tab 🛡️ Aset Terjaga, pilih aset, periksa kondisi gembok, jepret foto fisik, dan klik Submit.
  5. Bila Ada Insiden/Demo: Buka tab ⚠️ Lapor Insiden / 📢 Intel untuk kirim laporan kilat ke Command Center.
Sistem dapat dijalankan secara offline di intranet hauling ataupun online di jaringan publik.
